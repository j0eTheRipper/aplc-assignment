# Advanced Programming language concepts assignment: Car searching

This Serves as a document for the future developer to refer to when in doubt.

For windows, this project requires installation of the following:
- node.js
- npm
- yarn

To install node.js and npm, execute the following command in the terminal:
```
winget install --id OpenJS.NodeJS.LTS -e
```
You can run  `node -v` to check if node was installed correctly.

You can run  `npm -v` to check if npm was installed correctly.

To install yarn, execute the following command in the terminal:
```
npm install --global yarn
```
To install the dependencies of the project, execute the following command:
```
yarn install
```
To run the project, execute the following command:
```
yarn serve
```
